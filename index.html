ツールの説明：

  • リッチテキスト（書式付きテキスト）の差分を比較できるツールです
  • 太字・斜体・下線・上付き・下付きの書式変化も検出・表示します
  • 完全ローカル処理 — テキストはサーバーに送信されません
  • Word や Google Docs からコピー&ペーストで書式を保持したまま入力できます
  • difff《デュフフ》に着想を得たリッチテキスト対応の比較ツールです

基本の使い方：

  • ① 左エディタ（A）に変更前、右エディタ（B）に変更後のテキストを貼り付ける
  • ② 比較するボタン（または Ctrl+Enter）を押す
  • ③ 差分が色分けで表示される — ●削除・●追加・●書式変更
  • ④ ▼次の差分 / ▲前の差分 で差分箇所をジャンプ
  • ⑤ … メニュー → HTMLで保存 で差分結果をファイルに書き出し

詳しい機能：

  • インライン差分 — 変更行の中で「どの文字が」変わったかを文字単位で強調
  • 改行位置の自動整列（v1.9）— 一方のテキストに余分な改行がある場合、自動で行を連結して差分を取り直す。結合箇所は ↲ で視覚化
  • 書式差分の検出 — 文字列が同じでも太字・斜体・下線などが変わった行を「書式変更」として識別
  • 行高さ自動同期 — 折り返しが生じても左右の対応行の高さを揃えて表示
  • 入力エリアのスクロール同期 — 比較後、左右エディタのスクロールが行対応で連動
  • エディタ内の書式操作 — Ctrl+B / Ctrl+I / Ctrl+U、またはツールバーボタンで書式を手動適用
  • Word貼り付け対応 — Word / Google Docs からのコピーで書式・スペースを正確に取り込む
  • 高さ調整 — リサイズハンドルまたは S / M / L / XL ボタンでエディタ高さを変更
  • ダーク / ライトテーマ — … メニューで切り替え。選択はブラウザに記憶
  • HTML保存 — 差分結果をスタンドアロン HTML ファイルとして書き出し。横幅変更後も崩れないテーブル構造
  • 統計表示 — 変更行・削除行・追加行・書式変更行の件数を比較実行後に表示
  • 変更一覧の書き出し（v1.15）— 差分を「[変更] A12行目 → B12行目」形式のテキスト一覧にまとめ、… メニューからクリップボードへコピー、または .txt 保存。変更箇所だけをメールや校正指示に貼り付けられる。書式変更は「『CO2』下付き追加」のように内容も明示
